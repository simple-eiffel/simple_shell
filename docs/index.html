The deferred model

SHELL_WINDOW is deferred. Events queue in C and drain through one polled loop — never $-callbacks, which SEGV under EIF_THREADS. A descendant supplies one thing: what an event means.

class MY_WINDOW

inherit
    SHELL_WINDOW

feature

    run
        do
            shell_run ("My app", 100, 100, 800, 600)
        end

    dispatch (a_type, a_x, a_y: INTEGER)
        do
            -- 2 press · 3 char · 4 key · 6 expose · 7 tick
            -- 9 drag · 10 release · 13 move · 15 wheel · 16 resize · 18 drop
        end

end

The classes

ClassService
SHELL_WINDOW(deferred) native window + queue-polled pump; DC access, backdrop brush, drag-drop paths, private fonts, native text menu, tick clock, cursor shaping
SHELL_KEYSphysical Shift / Ctrl / Alt state
SHELL_INPUTsynthesised mouse and keyboard through SendInput (1.8.0): click_at leaves focus where it landed, click_at_quietly restores pointer and foreground, press_chord / paste / press_enter, Unicode type_text with no clipboard; acceptance is a status (was_accepted, last_os_error), never a promise - it needs the interactive desktop
SHELL_CLIPBOARDUnicode text get/set, history-manager retry, 1M-character headroom; set_image puts an ARGB32 bitmap on the clipboard as CF_DIB (1.8.0), has_image / image_width / image_height read what is there
SHELL_SPELLERWindows inbox ISpellChecker: ranges + suggestions; degrades, never fails
SHELL_DESKTOPvirtual-screen metrics, pure screen grab into ARGB32, QPC clock, minutes-of-day, open-externally
SHELL_OVERLAYfrozen-desktop topmost overlay (region-picker pattern)
SHELL_STRIPtopmost tool-window strip (dictation-bar pattern)
SHELL_OUTLINESclick-through coloured frame regions (region-outline pattern)
